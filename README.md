# Ropeway

Приложение для компьютеров в одной локальной сети: сообщения, передача файлов,
общая папка, трансляция экрана и удалённое управление. Сервер не нужен: все
устройства равноправны и находят друг друга сами.

## Статус

| Этап | Что входит | Состояние |
|---|---|---|
| 1 | Обнаружение ПК, шифрование, доверенные устройства, личный и общий чат, трей, автозапуск | **готово** |
| 2 | Отправка файлов и папок (докачка, drag-and-drop), общая папка с одобрением изменений | **готово** |
| 3 | Трансляция экрана одному или нескольким ПК, системный звук и микрофон | **готово** |
| 4 | Удалённое управление: мышь, клавиатура, буфер обмена, мониторы, звук | **готово** |
| 5 | Темы оформления: Fluent, Material, Neumorphism, Liquid Glass, Retro, редактор и обмен темами | **готово** |

## Архитектура

```
crates/ropeway-core   ядро на Rust без зависимостей от UI и ОС-специфичных API
  identity.rs         постоянный самоподписанный сертификат устройства; id = SHA-256 отпечаток
  tls.rs              QUIC + взаимный TLS 1.3 с привязкой к отпечатку вместо центра сертификации
  discovery.rs        UDP-broadcast анонсы на порту 47800
  protocol.rs         запрос/ответ на отдельном QUIC-потоке, кадры «длина + JSON»
  node.rs             узел: соединения, присутствие, маршрутизация, доставка и повтор сообщений
  chat.rs             история чатов (JSON Lines на диалог)
  transfers.rs        передача файлов и папок: предложение, приём, докачка, прогресс
  shared.rs           общая папка: список, копирование, правки и удаление с одобрением владельца
  fs_util.rs          безопасная работа с путями из сети, обход папок
  screen.rs           трансляция и управление: приглашения, запросы, раздача потока, приём ввода
  settings.rs         настройки, папки и список доверенных устройств
crates/ropeway-media  захват и кодирование для трансляции
  encoder.rs          BGRA → H.264 (OpenH264), общий для всех платформ
  audio.rs            системный звук и микрофон (cpal), смешивание в 48 кГц стерео
  clipboard.rs        синхронизация текстового буфера обмена (arboard)
  keymap.rs           физические коды клавиш → скан-коды
  video_windows.rs    захват монитора или окна (Windows Graphics Capture)
  input_windows.rs    мышь и клавиатура через SendInput
src-tauri             оболочка Tauri 2: команды для UI, трей, автозапуск, уведомления
src                   интерфейс на React + TypeScript, переводы ru/en
```

Ядро не знает о Tauri, поэтому его можно без изменений использовать на Linux,
macOS и Android. Кодирование видео и звук в `ropeway-media` тоже переносимы.
Для новой платформы нужно написать только `video_<ос>.rs` с захватом экрана,
и `input_<ос>.rs` с эмуляцией ввода.

**Безопасность.** Весь трафик шифруется (QUIC/TLS 1.3, взаимная аутентификация).
Id устройства — это отпечаток его сертификата. При подключении к известному
устройству отпечаток проверяется, поэтому другой компьютер в сети не может
выдать себя за доверенный. Чтобы убедиться, что это то самое устройство,
сравните код вида `3FA2-91C0-7B1E` на обоих компьютерах (он есть в Настройках).

## Файлы и общая папка

**Отправка.** Кнопка «Файлы» в чате с устройством или перетаскивание файлов
и папок на окно. Структура папок, включая пустые, сохраняется. От доверенных
устройств файлы принимаются сразу, от остальных — после «Принять». Полученное
сохраняется в `Загрузки\Ropeway` (меняется в Настройках). Если имя занято,
к нему добавляется « (1)».

**Докачка.** Файлы всегда «скачивает» получатель с нужного места. Недокачанное
лежит рядом как `*.ropeway-part`. Если связь пропала или один из компьютеров
перезапустился, передача продолжится сама, как только устройство снова
появится в сети. Если исходный файл изменили после отправки, передача
остановится с ошибкой, а не соберёт смесь двух версий.

**Общая папка.** У каждого компьютера своя папка (по умолчанию
`Документы\Ropeway Shared`), её видят все в сети. Чужие файлы и папки можно
скопировать к себе. Чтобы изменить чужой файл, нажмите «Изменить»: копия
откроется в программе по умолчанию. Сохраните её и нажмите «Отправить
изменения». Владелец получит запрос, и только после «Одобрить» новая версия
заменит файл. Удаление тоже идёт через запрос владельцу. Заменённые и удалённые
файлы попадают в Корзину владельца, а не стираются. Пути из сети проверяются,
так что выйти за пределы общей папки нельзя.

## Трансляция экрана

**Показать свой экран.** В чате с устройством: «Трансляция → Показать мой экран…»,
в общем чате: «Показать экран». Можно выбрать монитор или отдельное окно,
звук компьютера и микрофон, а также кому показывать: отдельным устройствам или
всем в сети. В последнем случае подключившиеся позже тоже получат приглашение.
Получатели видят полосу «… показывает экран — Смотреть», трансляция открывается
в отдельном окне. Пока идёт трансляция, вверху окна горит красная полоса
со списком зрителей и кнопкой «Остановить», а Windows рисует жёлтую рамку
вокруг того, что показывается.

**Посмотреть чужой экран.** «Трансляция → Попросить показать экран». Владелец
видит запрос «Разрешить / Отклонить». Доверенным устройствам разрешается сразу,
но красная полоса со зрителями у владельца есть всегда.

**Качество.** В диалоге «Показать экран» выбираются разрешение («Авто», «Как на
экране», 1440p, 1080p, 720p), частота (15, 30 или 60 кадров/с) и качество
(экономное, стандартное, высокое). Выбор запоминается и используется, когда
другой компьютер просит показать экран или управлять им. Его же можно задать
в Настройках. Тот, кто управляет или сам попросил показать экран, может менять
качество прямо в окне просмотра (кнопка ⚙ на панели). 60 кадров/с
и высокое качество сильнее нагружают процессор и сеть. Если 60 не держится
(обычно на мониторах больше 1080p при сильном движении), выберите 1080p.

**Окно просмотра.** Панель управления прижата к верхнему краю, сворачивается
кнопкой ▴ в маленький ярлычок и перетаскивается вдоль края за ручку ⋮⋮, чтобы
не закрывать панель задач или кнопки окон. Положение запоминается. В режиме
управления панель сначала свёрнута.

**Как это устроено.** Кадры захватываются при изменениях на экране по
расписанию нужной частоты, кодируются в H.264 один раз (кадр режется на
слайсы, каждый кодируется в своём потоке) и рассылаются всем зрителям.
Если зритель не успевает, он пропускает кадры до ближайшего ключевого
и не тормозит остальных. Звук идёт без сжатия (48 кГц, 16 бит, стерео, около
1,5 Мбит/с). Окно просмотра декодирует видео аппаратно через WebCodecs.

## Удалённое управление

В чате с устройством нажмите «Управление». Владелец компьютера увидит
«… хочет управлять вашим компьютером — Разрешить / Отклонить». Доверенным
устройствам разрешается сразу. После согласия откроется окно с экраном
того компьютера.

- **Мышь и клавиатура.** Передаются физические клавиши, поэтому на удалённом
  компьютере действует его раскладка: переключайте её там как обычно.
  Сочетания вроде Ctrl+R или Alt+F4 уходят на удалённый компьютер, а не
  закрывают окно. Win+… и Ctrl+Alt+Del Windows перехватывает раньше
  приложения, поэтому для клавиши Win на панели есть отдельная кнопка.
- **Буфер обмена.** Текст, скопированный на одном компьютере, можно вставить
  на другом, в обе стороны.
- **Мониторы.** Переключаются на панели вверху окна.
- **Звук.** Слышно то, что играет на удалённом компьютере.
- **Только просмотр.** Кнопка «Управление включено» на панели временно
  выключает передачу ввода.

**Безопасность.** Пока вашим компьютером управляют, поверх всех окон висит
красная полоса «… управляет вашим компьютером — Отключить», а Windows рисует
жёлтую рамку вокруг экрана. Ввод принимается только от устройства, которому
вы разрешили управление: тот, кто просто смотрит трансляцию, управлять
не может. Если связь оборвалась или окно закрыли, все зажатые клавиши
и кнопки мыши отпускаются. Окна, запущенные от имени администратора,
управлению недоступны: это ограничение Windows для программ без прав
администратора.

**Журнал.** Приложение пишет `ropeway.log` в папку данных. Подробный журнал
для диагностики: запустите с переменной `RUST_LOG=info,ropeway_core=debug,ropeway_media=debug`.

**Сеть.** UDP 47800 — обнаружение устройств, UDP 47801 — соединения. При первом
запуске Windows спросит разрешение для брандмауэра: разрешите доступ в
**частных** сетях. Если broadcast в сети заблокирован, добавьте компьютер кнопкой
«Добавить по IP»: адрес запомнится, и подключение будет восстанавливаться само.

## Оформление

Настройки → «Оформление». Тема меняет стиль элементов, раскладку окна, шрифт,
иконки и характер анимаций. Светлый или тёмный режим выбирается отдельно, если
тема поддерживает оба.

| Тема | Раскладка | Особенности |
|---|---|---|
| Fluent (по умолчанию) | Панель навигации, сворачивается до иконок | Mica, акцентный цвет Windows, анимации WinUI |
| Material | Navigation rail + список чатов | Тональная палитра из акцента, Roboto, ripple-эффект |
| Neumorphism | Две «парящие» панели | Выпуклые и вдавленные элементы, Nunito |
| Liquid Glass | Две «парящие» панели | Стекло с бликами по краям над цветными обоями из акцента, иконки SF Symbols |
| Retro | Два окна на бирюзовом столе | Windows 98: объёмные рамки, синие заголовки, цветные пиксельные иконки; только светлый режим |
| Ropeway | Классическая боковая панель | Исходный вид приложения |

**Акцент.** Цвет темы, «Как в Windows», одна из готовых палитр или свой цвет.
**Анимации.** Полные, умеренные или выключены. Если в Windows отключены
эффекты анимации, полные анимации становятся умеренными.

**Свои темы.** «Создать тему» копирует текущую и открывает редактор: стиль
элементов, раскладка, набор иконок, режимы, цвета для каждого режима,
скругления, шрифт, скорость анимаций, Mica и свой CSS. Изменения видны сразу.
Темы хранятся в папке данных, в `themes/`.

**Файл темы** — JSON с расширением `.ropeway-theme` (до 512 КБ):

```json
{
  "format": "ropeway-theme",
  "version": 1,
  "id": "my-theme",
  "name": "Моя тема",
  "base": "fluent",
  "layout": "navview",
  "icons": "fluent",
  "modes": ["light", "dark"],
  "accent": "#0067c0",
  "colors": { "light": { "bg": "#f3f3f3" }, "dark": { "bg": "#202020" } },
  "radius": 8,
  "motion": 1,
  "mica": true,
  "css": "[data-mode=dark] .bubble { letter-spacing: .01em }"
}
```

`base`: `fluent`, `material`, `neu`, `glass`, `retro`, `ropeway`. `icons`:
`fluent`, `material`, `puffy`, `glass`, `retro`, `ropeway`. `layout`: `navview`, `rail`,
`soft`, `sidebar`. Цвета, которых нет в файле, выводятся из акцента. Свой CSS
применяется поверх стилей приложения; на `<html>` доступны атрибуты
`data-base`, `data-layout`, `data-mode` и переменные `--accent`, `--bg`,
`--panel`, `--text` и другие.

Тему можно сохранить в файл, загрузить из файла или отправить на другой ПК:
у получателя в карточке файла появится кнопка «Установить тему».

Иконки: [Icons8](https://icons8.com) (наборы Fluent, Material Rounded, Puffy,
Apple SF Symbols, Retro).
Скрипт `scripts/fetch-icons.py` скачивает их заново.

## Linux

Пакеты: AppImage (запускается без установки), `.deb` (Ubuntu, Debian, Mint) и
`.rpm` (Fedora, openSUSE). Собираются на Ubuntu 22.04, чтобы работать и на
более новых системах: `scripts/linux/provision.sh` готовит машину,
`scripts/linux/build.sh` собирает пакеты в `releases/`.

Трансляция и управление:

- **X11** — захват экрана напрямую (MIT-SHM), ввод через XTest.
- **Wayland** (GNOME, KDE) — через системный портал. При первом показе система
  спрашивает, какой экран показать; для управления включите «Allow Remote
  Interaction». Выбор запоминается отдельно для показа и для управления.

Брандмауэр (если устройства не находятся): `sudo ufw allow 47800:47801/udp`.

## macOS

Собирается на GitHub Actions (`.github/workflows/macos.yml`): универсальное
приложение для Apple Silicon и Intel, macOS 13 и новее. Готовый `.dmg` — в
артефактах запуска.

Приложение не подписано, поэтому при первом запуске macOS его заблокирует.
Разрешить: Системные настройки → Конфиденциальность и безопасность → «Всё
равно открыть» (или в терминале `xattr -dr com.apple.quarantine /Applications/Ropeway.app`).

Разрешения, которые macOS попросит:

- **Локальная сеть** — чтобы находить другие устройства;
- **Запись экрана** — при первом показе экрана;
- **Универсальный доступ** — чтобы с другого устройства можно было управлять
  этим Mac.

Команды в терминале: `/Applications/Ropeway.app/Contents/MacOS/ropeway help`
(удобно сделать ссылку: `ln -s /Applications/Ropeway.app/Contents/MacOS/ropeway /usr/local/bin/ropeway`).

## Команды в терминале

`ropeway help` — список команд. Если Ropeway не запущен, команда запустит его
в фоне (в трее). `ropeway daemon` — работа без окна, для серверов; открытое
потом окно заменит фоновый режим. Устройство указывается именем, кодом или
началом id; `--json` — вывод для скриптов. Работает и на Windows.

```
ropeway peers                       устройства в сети
ropeway send test-a привет          сообщение (all — общий чат)
ropeway files test-a ./отчёт.pdf    отправить файлы
ropeway watch                       следить за сообщениями и файлами
ropeway accept 1a2b3c4d             принять входящие файлы
ropeway shared test-a               общая папка устройства
```

## Сборка

Нужны: Rust (stable, MSVC), Node.js 20+, Visual Studio с компонентом
«MSVC x64/x86 build tools» и Windows SDK.

Для быстрого кодирования видео нужен [NASM](https://www.nasm.us/) в `PATH`
во время сборки: с ним OpenH264 собирается с ассемблерными оптимизациями
(кадр 1080p кодируется за ~10 мс вместо ~90 мс). Без NASM сборка тоже
работает, но трансляция будет медленной. Пользователям приложения NASM
не нужен.

```bash
npm install
```

```bash
npx tauri dev
```

```bash
npx tauri build
```

Установщик появится в `target/release/bundle/nsis/`, а сам исполняемый файл — `target/release/ropeway.exe`.

Тесты ядра: узлы обмениваются сообщениями, файлами и трансляцией через настоящее
зашифрованное соединение. Проверяются в том числе докачка после перезапуска, общая
папка, правки с одобрением, попытки выйти за пределы папки, приглашения и запросы
на просмотр экрана, приём ввода только от разрешённого управляющего и передача
буфера обмена. Тесты медиа проверяют, что закодированный поток декодируется,
ключевые кадры выдаются по требованию, а коды клавиш не пересекаются.

```bash
cargo test -p ropeway-core -p ropeway-media
```

Скорость кодирования на этом компьютере:

```bash
cargo test --release -p ropeway-media encoding_speed -- --ignored --nocapture
```

Проверка пересчёта координат мыши на настоящем курсоре (курсор ненадолго
переместится и вернётся на место):

```bash
cargo test -p ropeway-media inject -- --ignored
```

## Два экземпляра на одном ПК

Для проверки без второго компьютера запустите второй экземпляр с отдельной папкой данных.
В этом режиме отключена блокировка второго экземпляра, а заменённые и удалённые файлы
общей папки уходят не в Корзину, а в подпапку `removed` папки данных:

```powershell
$env:ROPEWAY_DATA_DIR = "$env:TEMP\ropeway-second"; .\target\release\ropeway.exe
```

Данные приложения: `%APPDATA%\app.ropeway.desktop` (ключ устройства, настройки, история
чатов, список передач и запросов, копии файлов для правки в `edits`).
